# Windows 用户必读 🪟

## ✅ 好消息！

这个项目在 **Windows 上完全兼容**！所有功能都经过测试并正常工作。

## 🚀 3 步快速开始

### 1️⃣ 运行测试脚本

打开 PowerShell，进入项目目录：

```powershell
.\test-windows.ps1
```

或使用 CMD：

```cmd
test-windows.cmd
```

### 2️⃣ 复制配置

脚本会生成配置示例，复制到 `.kiro\settings\mcp.json`

### 3️⃣ 开始使用

在 OpenClaw 中输入：

```
启动浏览器，访问 example.com
```
